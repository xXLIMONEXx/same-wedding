# 同一个婚礼 · The Same Wedding

一个基于真实医学事实的交互式叙事作品，关于 **红细胞生成性原卟啉症（EPP）** 患者。

观众将跟随一位 EPP 患者参加最好朋友的户外婚礼——画面在"普通宾客视角"与"患者视角"之间不规律跳跃：同一片阳光明媚的草坪，在患者眼中却是逐渐加剧的痛苦折磨。故事以晕厥为转折，延伸至医院与三个月后的餐厅偶遇，最终揭示误解造成的友谊破裂。

**在线体验**：`https://<你的用户名>.github.io/same-wedding/`

## 特性

- 双视角自动跳跃叙事（16 个婚礼画面，患者痛苦 7 级递进）
- 全部场景为手绘 SVG 矢量插画，零外部依赖，单文件运行
- 人物互动动画：交谈摇摆、伸手抚摸、拥抱倾身、手势指责、落泪、颤抖等
- 完整四幕结构：婚礼 → 医院 → 三个月后的餐厅 → 结尾追问
- 内置 EPP 科普知识页与信息来源

## 操作

- 自动播放（每景 3–5 秒），点击画面 / 空格 / → 键手动前进
- 右上角暂停（快捷键 P），顶部进度条显示推进位置

## 说明

本作品基于真实的医学事实和患者经历，但具体情节为艺术创作。每位 EPP 患者的症状严重程度不同。
